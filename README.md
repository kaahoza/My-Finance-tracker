# My-Finance-tracker - Persnal Finance Tracker
fullstact python project 

# Problem statement
Young working professionals in South Africa have no simple way to track daily spending, identify patterns, or get actionable advice. They overspend without realising it and have no early warning system before month-end financial stress hits.

# Target users
Persona 1

Name:       Thabo Nkosi, 26
Job:        Junior accountant, Cape Town
Income:     R18,000/month, fixed salary
Pain:       Knows his salary but has no idea 
            where it goes by the 20th of the month
Goal:       Wants a simple breakdown — food, 
            transport, entertainment
Tech comfort: Uses smartphone daily, not very 
              technical

Persona 2

Name:       Naledi Dlamini, 31
Job:        Freelance graphic designer
Income:     Variable — R8,000 to R25,000/month
Pain:       Difficult to budget with irregular 
            income, scared of tax season
Goal:       Track multiple income sources, 
            see average monthly income trend
Tech comfort: Comfortable with web apps
